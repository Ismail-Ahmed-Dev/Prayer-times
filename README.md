# 🕌 Prayer Times App

A simple web application to display **daily prayer times** for different cities using [Aladhan API](https://aladhan.com/prayer-times-api).

## 📌 Features
- Shows daily prayer times (Fajr, Sunrise, Dhuhr, Asr, Maghrib, Isha).
- Ability to select a city from a dropdown list.
- Displays both **Hijri** and **Gregorian** dates.
- Simple and responsive design using **HTML - CSS - JavaScript**.
- Fetching data via **Axios** library.

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript**
- **Axios**
- **Aladhan API**

## 🚀 How to Run
1. Clone or download the project.
2. Open `index.html` in your browser.
3. Select your city from the dropdown and view its prayer times.
